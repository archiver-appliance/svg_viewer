# svg_viewer
This is a web based viewer for the EPICS Archiver Appliance that uses SVG instead of Canvas with the potential to use WebGL in the future. 


# Software stack
- Vanilla javascript
- HTML and CSS
- Typescript
- Automatic linters
- No frontend frameworks
- Few dependencies (third party libraries) as possible, keep moment.js and plotly.js, more dependencies can be discussed
